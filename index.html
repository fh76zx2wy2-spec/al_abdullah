اللعبة الجماعية المباشرة تحتاج قاعدة بيانات مجانية (Firebase) تربط جهاز المضيفة بجوالات الجميع لحظيًا. خذي 5 دقائق وسوّي هذي الخطوات مرة وحدة بس:
1) ادخلي على console.firebase.google.com وسجلي دخول بحساب Google، ثم "Add project" وأنشئي مشروع جديد (مجاني بالكامل).
2) من القائمة اليسرى: Build ← Firestore Database ← Create database، اختاري "Start in test mode" ثم أي موقع سيرفر قريب.
3) من ⚙️ Project settings (بجانب Project Overview) ← نزلي لتبويب "Your apps" ← اضغطي أيقونة الويب ← سمّي التطبيق أي اسم ← Register app.
4) بيظهر لك كود فيه firebaseConfig = {...} — انسخي القيم وحطيها مكان القيم الوهمية داخل ملف اللعبة (ابحثي عن كلمة CONFIG في أول السكربت).
5) ارجعي لـ Firestore Database ← تبويب Rules ← امسحي الموجود والصقي القواعد هذي واضغطي Publish:

ملاحظة: هذي القواعد مفتوحة لأن اللعبة بدون تسجيل دخول — مناسبة لجلسة عائلية خاصة يشارك فيها الرمز مع المقربين فقط، مو للنشر العام.

بعد ما تحطين القيم الصحيحة مكان CONFIG في الكود وتحفظين الملف، افتحيه من جديد وبيختفي هذا الشرح تلقائيًا.
